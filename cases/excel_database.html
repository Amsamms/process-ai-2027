Case 18Everyday tool11 to 12 October 2026

Five monthly Excel files into one database

Every formula rewritten, 132 days moved, and one day replayed until 7,000 of 7,000 values matched.

The problem

One plant area kept its daily numbers in a new Excel file every month, one column per day, 85 sheets each. Two other units already used one continuous database workbook that a macro fills every day from the control system and lab files. I wanted the same for this area, without losing any data or any of the existing calculations.

What the AI did

  1. Sent three helpers in parallel to map the target layout, every sheet and formula of the old file, and how each daily file feeds it.
  2. Asked me four questions only I could answer (history period, lab import, report layout, who tests it), then wrote a 6 task plan that I approved.
  3. Rewrote 6,917 day by day formula columns into the one row per day form, with none left for manual work, and moved 132 days of history from 5 monthly files.
  4. Built the workbook with the same macros as the other units, so the daily run happens in Excel on the work PC.
  5. Replayed a real day and compared it with the old file: 7,000 of 7,000 values matched. When a check passed first time, it broke a value on purpose to prove the check could fail.
  6. Had a fresh reviewer read the whole job. It found about 21,000 old cells that were not moved; they were recovered and a permanent test was added.

The result

One database workbook in place of five monthly files. On 10 October every one of 7,000 compared values matched the old file, and the lab chain matched 473 of 473. After my comments the next day, the final book has 91 sheets and passes 146 tests.

What the engineer still did

I chose the history period, pointed it to the lab lookup already in the old macros, and sent a comments file that reshaped the layout. A colleague runs the acceptance test in Excel on the work PC, with a few days in parallel with the old file, before it replaces it.

Time taken

2 hours 40 minutes from my request to the reviewed and fixed version (session times); my changes over the next day.

Guardrails

The old files were only read. Everything was built on a separate branch with no merge and no push, and the new book is not used until a colleague accepts it in Excel.

Copy it

Give the AI the old file, one good example of the target layout, and a few real daily input files. Ask it to replay a real day and compare every value with the old file, and to have a fresh reviewer look at the whole job before you test it.
