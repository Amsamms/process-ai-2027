A flowmeter calculator, built and tested

A spreadsheet for orifice meter maximum flow, built from one method document and checked 72 ways.

The problem

Plant flowmeters (orifice plates and venturis) are set up for design conditions. To trust a reading, or to check that a meter's design maximum matches the control system range, the engineer has to redo the orifice calculation. Our old template used older correlations and could not be traced to one method.

What the AI did

  1. Read the licensor's orifice method document, zooming into each of 12 equations at high resolution so nothing was misread.
  2. Wrote an independent Python model of the same method first, to have something to check the spreadsheet against.
  3. Generated the spreadsheet with no macros: 7 meter types, gas, liquid and steam, with the coefficient and Reynolds number loop solved in 30 hidden passes.
  4. Filled test copies with 27 cases, recalculated them and compared every result with the Python model: 0 failures.
  5. Added a status line per meter that names the problem (missing input, out of range, not converged) instead of showing a wrong number.
  6. On my request, added a second sheet on the ISO 5167 orifice standard, so the two methods can be compared.

The result

A first tested calculator 13 minutes after the request. On the worked example it gives 6,314.3 Nm3/h against 6,311.5 from the old template, and the ISO 5167 sheet gives 6,291.1 (0.37 % lower). After 6 rounds of changes the checks stood at 36 cases on 2 sheets, 72 checks, 0 failures.

What the engineer still did

I found a fault its own tests missed: Excel reported a repair error that LibreOffice did not (an empty drop-down block on one sheet). I also decided the units, inputs and layout, and told it to take the method's printed constants as correct where it had flagged them. A colleague and I still review the method choices before real use.

Time taken

13 minutes from the request to the first tested version (session times); changes over the next day.

Guardrails

One source for the method, named in the request. Every version was re-tested against the independent model before it was sent, and it went to a colleague for review, not into use.

Copy it

Give the AI the one method document you trust and say it is the only reference. Ask for an independent model in code plus a spreadsheet, and a script that compares the two on many cases. Then open the file in the program your colleagues really use.
